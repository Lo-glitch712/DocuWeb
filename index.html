Using your own Google project
  1. Open Google Cloud Console → Credentials.
  2. Enable the Google Drive API for your project.
  3. Create an OAuth client ID of type Web application.
  4. Add this page's origin to Authorized JavaScript origins:
  5. Paste the Client ID above and save. It stays on this device.
