DocuFrame Responsive Camera + Gallery

Updates:
- Fullscreen camera experience on desktop/mobile.
- Camera resolution selector: Native/Highest available, 1920x1080, 1280x720, 940x788, Custom.
- Native camera mode uses the camera track's reported width/height instead of forcing 940x788.
- JPEG capture quality set to 0.96.
- Front/rear camera switch.
- Live overlay remains visible while composing the camera shot.
- Gallery opens a full preview grid of all loaded photos.
- Gallery actions: Select All, Delete Selected, Edit Selected.
- Removed Edit tab from the bottom panel. The panel now shows editing controls directly, while Info is a button in the bottom toolbar.
- Responsive desktop/tablet/mobile portrait/mobile landscape layouts.

Note: Browser camera APIs can only use resolutions actually offered by the device/browser. Native/Highest available requests the highest practical camera mode and preserves its captured pixel dimensions.
