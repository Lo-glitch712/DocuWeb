DocuFrame — Responsive Mobile/Desktop Build

This build keeps the 940×788 document workspace but makes the WEBSITE responsive.

Responsive behavior:
- Desktop: Photos | Canvas | Properties
- Tablet: compressed 3-column layout
- Phone portrait: Canvas/toolbar → horizontal photo strip → properties
- Phone landscape: 3-column compact layout
- Automatically reacts when the device rotates
- Uses 100dvh, CSS Grid/Flexbox, aspect-ratio and touch-friendly controls
- Export resolution is independent of the screen size; selected output resolution is preserved.

Other retained features:
- Batch image import
- Transparent PNG template overlay
- Camera with live overlay
- Zoom/X/Y/rotation/brightness/contrast
- Project/custom text
- Resolution choices including Original and Custom
- No automatic saved date/time watermark

Open index.html in a modern browser. For camera access on a phone, use HTTPS (GitHub Pages works) or localhost.
